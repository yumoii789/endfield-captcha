# 关卡系统规格 V1-V5（难度 5 级）

依据：用户设计稿（难度 5 级 V1-V5 = 简单/容易/中等/较难/困难）、C/D 调研、各游戏实现现状。

## 一、各游戏难度参数表

### V1 源石电路（index.html，生成型）
| 级 | 网格 n | 叶子数(目标灯数) | 说明 |
|---|---|---|---|
| V1 | 4 | 3-4 | 单源少灯，教学 |
| V2 | 4 | 5-7 | 分支管件增多 |
| V3 | 5 | 4-6 | 场地扩大 |
| V4 | 5 | 6-8 | T/十字件多 |
| V5 | 6 | 7-10 | 最大规模 |
- 生成器参数化：genPuzzle 的 size 与 leaves 范围按上表；防无解检测保持（solveReject=0）。
- 最优旋转数 = Σ每块需旋转次数（生成时已知解）；3 星=玩家旋转数 ≤ 最优，2 星=≤最优×1.5，1 星=通关。

### V2 方块拼装（puzzle2-core.js + puzzle2.html，生成型）
| 级 | cols×rows | 禁区数 | 拼块数 |
|---|---|---|---|
| V1 | 5×5 | 0-1 | 6-7 |
| V2 | 5×6 | 1-2 | 7-8 |
| V3 | 5×6 | 2-3 | 6-7 |
| V4 | 6×6 | 3 | 9-10 |
| V5 | 6×7 | 3-4 | 10-11 |
- genPuzzle 增加 piecesMin/piecesMax 参数（替换固定 5..8）；分色计数/防无解检测保持。
- 【修订】块数列原值（4-5 等）与"拼块≤4格且必须铺满非禁区格"矛盾（5 块最多覆盖 20 格 < ~24 空格），已按可行域 [ceil(空格/4), 空格] 反推修正；L2 实现保留原规格值于 specPiecesMin/Max 供对账。
- 3 星=0 次非法放置，2 星=≤2 次，1 星=通关。

### V3 宝石神偷（game3-gems.html，手工关 12 → 扩 25）
| 级 | 关卡编号 | 设计原则 |
|---|---|---|

## 二、关卡数据格式（供管理后台上传/删除/禁用）
```json
{
  "game": "circuit | packing | gems | camping",
  "id": "circuit-3-a1",        // game-序号-短随机
  "lv": 3,                      // 1-5
  "name": "显示名", "desc": "一句话介绍", "play": "玩法说明",
  "params": { },                // 生成型：难度参数（见上表）；手工型（gems）：关卡定义
  "hand": { "start":[0,0], "goal":[6,6], "gems":[[3,0]] },  // 仅 gems
  "enabled": true
}
```
- 每游戏在 ?export=1 时向 console 输出当前局 level JSON（供管理后台上传）。
- localStorage 键：'endland-levels-<game>' 存用户上传的自定义关卡，游戏启动时与内置库合并（enabled=false 跳过）。

## 三、难度/关卡匹配（管理后台公式，本阶段先预留接口）
- 全局难度分布 P_g(d)（5 段概率条，Σ=1）；关卡级覆盖 P_l(d)（每关卡每难度 0-1）。
- 联合概率 ∝ P_g(d) × P_l(d)；匹配时先按关卡权重选关卡，再按归一化联合概率选难度。
- 本阶段游戏侧提供 LEVELS_META 导出（各难度可用性）：**9 个游戏页面已全部定义**（game3/game4/game6/game8/game9 原有；game1/puzzle2/game5/game7 于 2026-11-10 补齐，见 `docs/realplay.md` §三十二）。管理后台接入后可直接读取各页的该变量。

## 四、UI 要求
- 挑战界面顶部加难度选择：V1-V5 五个切换按钮（当前高亮），切换即按新难度重开一局。
- 通关印章统计行追加"难度 Vx + 星级（★★★☆☆）"；C 轮起同行为各关追加"失误 N"（语义与门控见 `docs/star-rubric.md` §四）。
- 旧参数兼容：?lv= 在 V1/V2/V4 语义改为难度 1-5；V3 的 ?stage=N 表示第 N 关、?lv=N(≤12) 兼容旧关卡号。
- ?debug=1/?selftest=1/?direct=1/?seed= 全部保持兼容；selftest 改为 5 档各跑 60 局。
