## 1. 世界线

### 1.1 时代背景

**纪元名：ENDLAND 纪元（终末纪元）· 第 47 年**

地表环境在第 39 年的一次失控事件后不再适合长期驻留。人类把可呼吸的区域收缩成若干座**穹顶城邦**，“防线”从此不再指一条边界线，而指**一整套判断谁是人的流程**。

- 大撤离之后，幸存人口中混入了大量**机械渗透体（Synthetic Infiltrator, SI）**——外观、体温、语音均可拟真，唯一稳定可测的差异是“**思考时的抖动**”：真人在决策前会有毫秒级的不规则停顿、误触与回溯，机械体则倾向于最短路径、零犹豫、零浪费动作。
- 于是识别不再依赖证件，而依赖**行为**。能不能通过校验，取决于你**怎么**做完一件手工活，而不是你**是谁**。
- 全球所有联网入口统一由**识别中心**签发通行印，没有印，任何终端都不会为你打开第二层权限。

## 2. 势力

### 2.1 识别中心（IDENTIFICATION CENTER，代号 `IC`）— 核心势力

- **性质**：运营全部人机验证流程的准官方机构。不设人类接线员，只有一条恒定语速的合成声线。
- **信条**：*“我们不问你是谁，我们只看你怎么做。”*
- **行为特征**：从不寒暄，从不解释，只在结论上盖章。通过时给出行为侧写（QUIPS），失败时只给一行错误码。
- **在 UI 中的存在**：终端打字机行的说话人、印章的签发方、toast 的措辞来源。

### 2.2 访客中心（VISITOR CENTER，代号 `VC`）

- **性质**：玩家所在。穹顶城邦的接待与登记窗口，也是识别中心唯一对外的物理接口。
- **信条**：*“请坐。请把双手放在台面上。”*
- **行为特征**：礼貌、疲惫、按键有回弹声。会替你多问一句“要不要再来一局”。
- **在 UI 中的存在**：登录卡片、操作员编号字段、“我不是机器人”勾选框、`formNote` 提示行。

### 2.3 灰域信使（THE ASHEN COURIER，代号 `AC`）

- **性质**：往来穹顶与灰域之间的走私者，也是机械渗透体零件的实际提供方。
- **信条**：*“只要能开门，谁在乎开门的是一双手还是一段脉冲。”*
- **行为特征**：从不说真话，但从不违约。
- **在 UI 中的存在**：失败吐槽的来源（设备“抢答”系统偶尔会引用信使的口吻）、以及设备日志里那些不该出现的记录。

### 2.4 校验设备集群（VERIFICATION UNIT CLUSTER，代号 `VU`）

- **性质**：4 台工业遗留设备，编号 `V-40053`~`V-40056`。被识别中心征用为行为采样台。
- **信条**：无信条。它们只提供“手感的摩擦力”。
- **在 UI 中的存在**：4 个关卡页面本体、合集页 4 张卡片、状态标签“待验证 / 已通过”。

### 2.5 拟真渗透体（SYNTHETIC INFILTRATOR，代号 `SI`）

- **性质**：本作唯一的“敌人”，但从未在屏幕上露脸。
- **信条**：无。它们不认为自己是敌人。
- **行为特征**：零犹豫、零误触、最短路径、毫秒级精准点击——这正是本作**最核心的玩法立意**：你能过关，恰恰因为你做得不够漂亮。
- **在 UI 中的存在**：`--bad` 红色错误码、失败弹窗标题“验证失败”、“未检出机器精度”这类正面行为标签。

## 4. 主线故事

**一句话**：你在例行巡检日进入访客中心，被识别中心判定为**疑似机械渗透体**，必须在 4 台校验设备上完成维修作业，用行为证明你是人类。

### 幕次结构（与终端流程台词对齐）

| 幕 | 场景 | 终端台词（可直接用） | 对应实现 |
|---|---|---|---|
| **第一幕 · 拦截** | 终端椅亮起，屏幕上出现“检测到自动化访问特征” | `IC // 检测到自动化访问特征。请依次通过 4 台校验设备的维修挑战以证明您是人类。` | 合集页 `hub.html` 顶部提示行 |
| **第二幕 · 采样** | 依次接入 V-40053 / V-40054 / V-40056 / V-40055 | `VC // 请坐。请把双手放在台面上。设备正在记录您的每一次犹豫。` | 4 个关卡页 + 合集页弹窗标题栏 |
| **第三幕 · 侧写** | 每过一关，识别中心给出行为侧写百分比 | `IC // 行为特征：点击间隔抖动明显 ✔ 人类概率 99.7%` | QUIPS 数组（已存在于各关） |
| **第四幕 · 盖章** | 4 台全部通过，弹出绿色印章“人类身份已确认” | `IC // 通行印已签发。身份已确认，欢迎回来，操作员。` | `.stamp` + `formNote` 改写 |

> **线上实现口径（2026-11-09 核对）**：本表「4 台设备」属世界设定层（集群 `V-40053`~`V-40056`，见 §1.3 / §2.4）。线上实际有 **9 台**（`V-40053`~`V-40061`），终端每次访问**随机派 1 台**（按概率分布加权，不依次跑 4 台）；「依次接入 V-40053 / V-40054 / V-40056 / V-40055」是叙事写法，不是终端行为。

### 失败分支

被判定渗透体时，不给出“你是机器人”，只给出**一行错误码 + 一句信使口吻的嘲讽**，然后允许重试——因为识别中心从不解释，只盖章。

## 7. UI 风格规范

### 7.1 色板 Token

> 沿用现有 `:root` 变量名，仅补充与规范化。**实现时优先复用 `index.html` 已有的变量命名**，新增项放在其后。

```css
:root{

  --bg-deep:#0d1217;   /* 棋盘/凹槽底 */
  --bg-line:#0e1318;   /* 输入框底 */
  --surface-1:#12171d; /* 卡片渐变下沿 */
  --surface-2:#161c23; /* 卡片渐变上沿 */
  --surface-3:#161d24; /* toast / 固定格 */
  --tile:#1a2129;      /* 格子默认 */
  --tile-alt:#20272f;  /* 格子交替 */

  /* 描边 */
  --line:#28313b;      /* 主描边 */
  --line2:#3a4550;     /* 次级描边 / hover */

  /* 文字 */
  --ink:#d9e0e7;       /* 正文 */
  --dim:#8a96a2;       /* 说明文字 */
  --mute:#5a6772;      /* 管线/标签/禁用 */

  /* 语义色 */
  --acc:#ffb100;       /* 官方指令黄：警示条、按钮、高亮 */
  --on:#ffcb4a;        /* 通电亮黄：激活态、发光 */
```

### 7.5 终端打字机动画参数

```css
.type{display:inline-block;overflow:hidden;white-space:nowrap;border-right:2px solid var(--acc);
  width:0;animation:type 1.8s steps(28,end) forwards,caret .8s steps(1) infinite}
@keyframes type{to{width:100%}}
@keyframes caret{50%{border-color:transparent}}
```

| 参数 | 值 |
|---|---|
| 速度 | **42 字符/秒**（`steps` 步数 = 字符数，时长 = 字符数 / 42 秒） |
| 逐行间隔 | **180 ms**（上一行结束到下一行开始） |
| 光标 | 2px `--acc` 竖线，闪烁周期 800ms，`steps(1)` 硬切 |
| 标点停顿 | 逗号 +90ms，句号 +220ms（JS 分段插入 `setTimeout`） |
| 跳过机制 | 点击/触碰任意位置立刻 `width:100%` 并清除所有定时器 |
| 降级 | `prefers-reduced-motion:reduce` 时直接显示全文，无光标 |
| 上限 | 单次最多 6 行；超出走「按键继续」 |
