> 方法：以 `?direct=1&lv=N&fast=1` 逐档加载，从页面内部状态与 HUD 读取参数。

## 过程中修掉的缺陷

**game3 的 `?lv=` 语义与其他 8 关不一致**（原为「关卡号」而非「难度档位」）：

- 后果：`terminal.html` 只传 `?direct=1&lv=N`，所以在协议流程里抽到 game3 时**难度档位失效，永远给 V1（简单）**；`hub` 因为额外传了 `?stage=lv*5-4` 才侥幸正确。
- 修复：`?lv=1..5` 统一解释为难度档位（取该档位下的关卡），`?stage=N` 仍作关卡号覆盖（hub 走这条），`?lv>=6` 保留旧的关卡号语义以兼容旧链接。
- 实测：直连 `lv=1..5` → 难度 V1..V5 且 id 落在对应档（如 lv=5 → id25 V5）；`lv=18` → id18（V4）旧语义可用；hub 选 V5 → `?lv=5&stage=21` → 难度 V5(困难)。
